# Nomad Market

Энэ бол бүтээгдэхүүн харуулах, сагслах, захиалга бүртгэх болон бараа удирдах боломжтой онлайн дэлгүүрийн prototype юм.

## Яаж ажиллуулах вэ

1. Node.js 18+ суулгана.
2. `npm install` командаар Three.js dependency-г суулгана.
3. 3D scene-ийн source-г өөрчилсний дараа `npm run build:showcase` командаар browser bundle үүсгэнэ.
4. Түр demo ажиллуулах бол PowerShell дээр `$env:DEMO_MODE = "true"` гэж тохируулна. Admin болон худалдан авагчийн demo нэвтрэх мэдээлэл: утас `88665428` / `72445428`, нууц үг `GaNq123@`.
5. Энгийн горимд өөрийн нууц үгийг `$env:ADMIN_PASSWORD = "12-оос дээш тэмдэгттэй-урт-нууц-үг"` гэж тохируулна.
6. `node server.js` командаар серверийг асаана.
7. `http://localhost:3000` хаягаар дэлгүүрээ, `http://localhost:3000/admin` хаягаар админы нэвтрэх хуудсыг нээнэ.
8. Худалдан авагч `http://localhost:3000/account` хаягаар нэвтрэх эсвэл бүртгүүлнэ. Бүртгүүлэхэд 12-128 тэмдэгт нууц үг шаардлагатай.
9. Дэлгүүрээс бараагаа сагслаад, сагсанд нэр, утас, хүргэлтийн хаягаа оруулж захиалга өгнө.
10. Захиалгууд admin хэсгийн `Хүлээн авсан захиалгууд` жагсаалтад харагдана.

Demo горим зөвхөн localhost дээр ажиллана; дээрх demo нэвтрэх мэдээллийг зөвхөн локал demo-д ашиглана. API сервер холбогдохгүй статик preview дээр demo товчнууд browser дотор түр нэвтрүүлнэ; энэ нь бодит хамгаалалт биш бөгөөд бүртгэл, өгөгдлийг серверт хадгалахгүй. Demo-г унтраахдаа `$env:DEMO_MODE = "false"` гэж тохируулж, өөрийн `ADMIN_PASSWORD`-ийг өгнө. Нийтийн серверт байршуулахдаа HTTPS ашиглаж, `NODE_ENV=production` болон `HOST=0.0.0.0` тохируулна. Хэрэглэгчийн бүртгэл `.data/customers.json` файлд scrypt hash-тай хадгалагдана. Энэ prototype нь бараа, захиалгыг одоо ч тухайн browser-ийн `localStorage`-д хадгалдаг тул хэрэглэгчийн бүртгэл нь захиалгын түүх үүсгэхгүй.

## Боломжууд

- Худалдан авагчийн бүртгэл, нэвтрэлт, гаралт
- Бараа нэмэх, засах, устгах
- Зураг upload эсвэл image URL ашиглах
- Ангиллаар шүүх, хайлт хийх, эрэмбэлэх
- Сагсанд хийх, тоо өөрчлөх
- Захиалга үүсгэх, нөөцөөс хасах, захиалгын төлөв шинэчлэх
- Бараа болон захиалгыг JSON файл болгон татах; барааг JSON-оос импортлох
- Утас болон жижиг дэлгэцэд тохирсон responsive загвар

## Захиалгын хадгалалтын хязгаарлалт

Одоогийн prototype захиалга, бараа, сагсыг `localStorage`-д хадгалдаг. Захиалга зөвхөн тухайн төхөөрөмж болон browser дээр харагдах бөгөөд дэлгүүр эзэмшигчид автоматаар илгээгдэхгүй. Нийтийн сайтаар бодитоор захиалга хүлээн авахын тулд backend/API болон мэдээллийн сан холбох шаардлагатай. Төлбөрийн систем одоогоор холбогдоогүй.
