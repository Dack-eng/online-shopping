# Nomad Market

Энэ бол бараа оруулах, засах, зураг upload хийх боломжтой энгийн online shop prototype юм.

## Яаж ажиллуулах вэ

1. `index.html` файлыг browser-оор нээнэ.
2. `Бараа удирдах` хэсгээс шинэ бараа нэмнэ.
3. Бараанууд `localStorage`-д хадгалагдах тул тухайн browser дээр дахин нээхэд хэвээр байна.

## Боломжууд

- Бараа нэмэх, засах, устгах
- Зураг upload эсвэл image URL ашиглах
- Ангиллаар шүүх, хайлт хийх, эрэмбэлэх
- Сагсанд хийх, тоо өөрчлөх
- JSON export/import

## Дараа нь нэмж болох зүйлс

- Admin login
- Backend database
- Захиалга хадгалах API
- Payment integration
- Domain болон hosting
