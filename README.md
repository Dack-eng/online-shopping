# Nomad Market

Энэ бол бүтээгдэхүүн харуулах, сагслах, захиалга бүртгэх болон бараа удирдах боломжтой онлайн дэлгүүрийн prototype юм.

## Яаж ажиллуулах вэ

1. Node.js 18+ суулгана.
2. PowerShell дээр админы нууц үгийг тохируулна: `$env:ADMIN_PASSWORD = "12-оос дээш тэмдэгттэй-урт-нууц-үг"`
3. `node server.js` командаар серверийг асаана.
4. `http://localhost:3000` хаягаар дэлгүүрээ, `http://localhost:3000/admin` хаягаар админы нэвтрэх хуудсыг нээнэ.
5. Дэлгүүрээс бараагаа сагслаад, сагсанд нэр, утас, хүргэлтийн хаягаа оруулж захиалга өгнө.
6. Захиалгууд нэвтэрсний дараа admin хэсгийн `Хүлээн авсан захиалгууд` жагсаалтад харагдана.

`ADMIN_PASSWORD`-ийг кодонд бичихгүй; сервер ажиллуулах бүрт тохируулна. Нийтийн серверт байршуулахдаа HTTPS ашиглаж, `NODE_ENV=production` болон `HOST=0.0.0.0` тохируулна. Энэ prototype нь бараа, захиалгыг одоо ч тухайн browser-ийн `localStorage`-д хадгалдаг тул серверийн нэвтрэлт нь admin хуудсыг хамгаалж байгаа болохоос өгөгдлийг төхөөрөмжүүдийн хооронд синк хийхгүй.

## Боломжууд

- Бараа нэмэх, засах, устгах
- Зураг upload эсвэл image URL ашиглах
- Ангиллаар шүүх, хайлт хийх, эрэмбэлэх
- Сагсанд хийх, тоо өөрчлөх
- Захиалга үүсгэх, нөөцөөс хасах, захиалгын төлөв шинэчлэх
- Бараа болон захиалгыг JSON файл болгон татах; барааг JSON-оос импортлох
- Утас болон жижиг дэлгэцэд тохирсон responsive загвар

## Захиалгын хадгалалтын хязгаарлалт

Одоогийн prototype захиалга, бараа, сагсыг `localStorage`-д хадгалдаг. Захиалга зөвхөн тухайн төхөөрөмж болон browser дээр харагдах бөгөөд дэлгүүр эзэмшигчид автоматаар илгээгдэхгүй. Нийтийн сайтаар бодитоор захиалга хүлээн авахын тулд backend/API болон мэдээллийн сан холбох шаардлагатай. Төлбөрийн систем одоогоор холбогдоогүй.
