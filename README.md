# Nomad Market

Энэ бол бүтээгдэхүүн харуулах, сагслах, захиалга бүртгэх болон бараа удирдах боломжтой онлайн дэлгүүрийн prototype юм.

## Яаж ажиллуулах вэ

1. `index.html` файлыг browser-оор нээнэ.
2. `Бараа удирдах` хэсгээс шинэ бараа нэмнэ.
3. Дэлгүүрээс бараагаа сагслаад, сагсанд нэр, утас, хүргэлтийн хаягаа оруулж захиалга өгнө.
4. Захиалгууд `Бараа удирдах` хэсгийн `Хүлээн авсан захиалгууд` жагсаалтад харагдана.

## Боломжууд

- Бараа нэмэх, засах, устгах
- Зураг upload эсвэл image URL ашиглах
- Ангиллаар шүүх, хайлт хийх, эрэмбэлэх
- Сагсанд хийх, тоо өөрчлөх
- Захиалга үүсгэх, нөөцөөс хасах, захиалгын төлөв шинэчлэх
- Бараа болон захиалгыг JSON файл болгон татах; барааг JSON-оос импортлох
- Утас болон жижиг дэлгэцэд тохирсон responsive загвар

## Захиалгын хадгалалтын хязгаарлалт

Одоогийн prototype захиалга, бараа, сагсыг `localStorage`-д хадгалдаг. Захиалга зөвхөн тухайн төхөөрөмж болон browser дээр харагдах бөгөөд дэлгүүр эзэмшигчид автоматаар илгээгдэхгүй. Нийтийн сайтаар бодитоор захиалга хүлээн авахын тулд backend/API болон мэдээллийн сан холбох шаардлагатай. Төлбөрийн систем одоогоор холбогдоогүй.

## Дараа нь нэмж болох зүйлс

- Admin login
- Backend database
- Захиалга хадгалах API
- Payment integration
- Domain болон hosting
